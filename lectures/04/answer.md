## 宿題

- 取り組んだレベル：基礎

- やったこと：演習の STEP 3 後の状態（総合 8/10、要確認 0件）を基準にして、rubric.md の「分かりやすさ」に「簡潔とは、質問への答えが3文程度までで、同じ内容を言い換えて繰り返していないこと。繰り返し（「つまり」で言い直すなど）があれば fail」と1行だけ書き足し、同じ labels.jsonl で再実行した。モデル・コード・他の基準は変えていない。

- 結果：
基準別の一致率（変更前 → 後）：根拠 9/10 → 10/10、範囲 9/10 → 9/10、ヒント 10/10 → 10/10、分かりやすさ 8/10 → 8/10、回の表示 8/10 → 8/10
  - 総合 8/10 → 8/10、coverage 100% → 100%、要確認 0件 → 0件、不一致 6件 → 5件
  - #03 分かりやすさ：LLM=pass（自分=fail）のまま変わらず。#04 分かりやすさ：LLM=fail（自分=pass）のまま変わらず。理由の文だけが、追記した規則（「つまり」での言い換え）に沿った表現に変わった。
  - 想定外の変化：分かりやすさには効かなかった一方で、#06 根拠の過検出（LLM=fail 自分=pass）が消えて根拠が 10/10 になった。

- 気づき・疑問：

具体的な条件を書いても、狙った #03・#04 の判定は動かなかった。#03 は自分が fail にした理由（前提を確認せず答えている）が、「簡潔さ・繰り返し」の基準に入っていないためと思う。基準に書いたことと、自分が実際に見ていた点がずれていた。
  - #04 は LLM が追記した規則どおり fail にした。ただ自分は内容の正しさを優先して pass にしており、講師は fail だった。この場合は LLM の方が講師の判断に近く、自分のラベルの方を見直す余地がある。
  - #06 根拠が変わったのは、追記した1行が根拠の判定に影響したのか、実行ごとのばらつきなのかは分からない。同じ rubric で何回か実行して、判定がぶれるかを見ないと区別できない。
  - 疑問：10件では1件の違いが10%に見える。基準の効果とノイズをどう区別すればよいか。
